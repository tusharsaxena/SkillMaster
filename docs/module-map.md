# Module map — Ka0s Skill Master

Every non-vendored file the TOC loads, in load order, with its one responsibility. The TOC's `#`
section headers fix the folder order `libs → locales → core → defaults → modules → settings`
(layout-§1); inside `core/` the order is what each file resolves at load, and each load-bearing
position says so beside its TOC line (toc-file-§5).

| File | Responsibility | Load-order note |
|---|---|---|
| `locales/enUS.lua` | `NS.L` with its key-is-the-string fallback | creates `NS.L`, read at load by DebugLogSetup and every settings file |
| `locales/<locale>.lua` | a translation stub per client locale (deDE, esES, esMX, frFR, itIT, koKR, ptBR, ruRU, zhCN, zhTW), gated on its own `GetLocale()` | fills `NS.L` at load, after every enUS file |
| `core/Namespace.lua` | folder name, version fallback, `[SM]` chat tag, library-missing sentence | first: every file reads it |
| `core/Compat.lua` | `NS.Compat`: the skill-list shims, one normalized line record from either return shape, the player, enchant, tooltip and speed reads the simulator answers, and the world positions behind the trainer popup's distances (`MapWorldPos`, `PlayerWorldPos`, round 5, R5-15) ([compat-layer.md](compat-layer.md)) | conventional: reached at call time |
| `core/SimSetup.lua` | `NS.SimSeam` (LibKa0s-Sim-1.0's seam over `NS.Compat`, the header toggle guarded), or the reference stub | straight after Compat: wraps every member at load |
| `core/MediaSetup.lua` | `NS.Icon`, `NS.MediaFont`, `RegisterLSM` (LibKa0s-Media-1.0) | before Constants, which resolves `FONT_MONO` from it |
| `core/Constants.lua` | brand, logo paths, monospace face, minimap path, `LAYERS` (with the player's strata choices and the strata above each) | read at load by the setup files below |
| `core/State.lua` | session-only state: the debug flag, test mode | conventional |
| `core/EnvSetup.lua` | `NS.Meta`, `NS.Version` (LibKa0s-Env-1.0) | conventional |
| `core/CoreSetup.lua` | `NS.Print`, SafeRegister family, window chrome, the `MakeCloseButton` wrapper (LibKa0s-Core-1.0) | before everything that prints |
| `core/SkinSetup.lua` | the skin owner and its tokens (the bar parts, the `sm.cat.*` category and `sm.bonus*` bonus colors), `NS.Skin`, the stored choice, the picker, the `skin` verb (LibKa0s-Skin-1.0) | registers at load; `NS.DEFAULT_SKIN` read by defaults |
| `core/Bus.lua` | `NS.MSG`, the bus record and targets (LibKa0s-Bus-1.0) | before any subscriber |
| `core/UnitEventsSetup.lua` | `NS.UnitEvents`: the one frame that hears the player's `UNIT_*` events through `RegisterUnitEvent`; stood up from `NS.RegisterRuntime`, down from `NS.StandDown` | before `modules/Bonuses.lua` and `modules/StatData.lua`, which register with it at load |
| `core/PoolSetup.lua` | `NS.Pool` (LibKa0s-Pool-1.0), for the rows and bars to come | conventional |
| `core/WidgetsSetup.lua` | `NS.Widgets` (LibKa0s-Widgets-1.0): the test strip | before the window |
| `core/LifecycleSetup.lua` | the stand-down latch, `NS.StoodDownRefusal` (LibKa0s-Lifecycle-1.0) | before PerfSetup, which hands it to Perf |
| `core/PerfSetup.lua` | `NS.Perf` and its buckets (LibKa0s-Perf-1.0) | before any file taking `NS.Perf` as an upvalue |
| `core/DebugLogSetup.lua` | `NS.DebugLog`, `NS.Debug` and its gates (LibKa0s-DebugLog-1.0) | after Constants, State and CoreSetup |
| `core/SkillMaster.lua` | AceAddon registration, `OnInitialize` / `OnEnable`, stand-down and stand-up, test mode | after CoreSetup: reclaims `NS.Print` from AceConsole |
| `core/Database.lua` | AceDB store and the migration runner | conventional |
| `core/LauncherSetup.lua` | the launcher object (LibKa0s-Launcher-1.0), registered OnEnable | conventional |
| `defaults/Profile.lua` | `NS.defaults`, the only place a default is written | read by the schema rows at load |
| `defaults/SkillCatalog_Forever.lua` | `NS.SkillCatalog` (every profession, the 16 weapon lines, Defense, Lockpicking, Riding) with each line's in-game `icon` and a profession's `iconSpellID`, `NS.SKILL_ICON_UNKNOWN`, the excluded Skills-tab headers, `NS.DataMeta` | read at load by SkillData |
| `defaults/ClassWeapons_Forever.lua` | `NS.ClassWeapons_Forever[classFile]`: the weapon lines and Riding each class can train | read at load by SkillData |
| `defaults/Ranks_Forever.lua`, `Trainers_Forever.lua`, `Gathering_Forever.lua`, `Fishing_Forever.lua` | the rank ladders, trainer records, gathering needs and fishing zones (all `verified = false`) | read at call time by Trainers and SkillHelpers; through `NS.L` at load |
| `defaults/Racials_Forever.lua` | `NS.Racials_Forever.byRace`: the +5 racial weapon skills | read at call time by Bonuses |
| `defaults/Stats_Forever.lua` | `NS.STAT_DEFS`: the 30 stats, their groups, references, markers and in-game icons | read at call time by StatData |
| `defaults/Preview_Forever.lua` | `NS.Preview_Forever`: test mode's sample character, Ember Ironsong, a level-22 Dwarf Hunter (the mockups'): skill lines, temp bonuses, stats, a session log and three alts | read at call time by Preview and the simulator |
| `modules/Bar.lua` | `NS.Bar`: the data bar (base, bonus segment clamped at the end, the fill split by rank tier on a scale to the last tier under Rank tier colors, threshold markers, spark, text, expiry timer), its resolved style and its pool | conventional: reads the skin, the pool and the profile at call time |
| `modules/Chrome.lua` | `NS.Chrome`: the title-bar and header icon controls (catalog marks, a glyph fallback, a mark turned 180 degrees: the attach mark; every mark's art snapped to the pixel grid, `Snap`, round 5; `HeaderMark`, a block header's mark cropped to its ink box, `INK`, and drawn at one size, `INK_SIZE`, centered, round 6) and `MakeResizable`, the one resize helper (a coalesced relayout per frame, the redraw and save on release) | conventional |
| `modules/Rows.lua` | `NS.Rows`: one skill or stat row (in-game icon in a thin border of the row's color, `Icon(kind, key)`; name, bar, timer; the unlearned variant with its trainer line; every skill row carries one action mark (`ph:sign-in`, `row.act`, round 3), which takes no mouse so the row's click (and on a crafting row the overlay over it) is the action; the mark in the block header's column (`GO_W`, `EDGE`, `BAR_RIGHT`); the icon's look from Bars > Icons, `IconStyle(rowColor, rowH)`), its pool and the pure helpers (values, colors, trainer line, money) | conventional |
| `modules/Blocks.lua` | `NS.BLOCKS`, `NS.BlockDefs`, `NS.Blocks`: the blocks `NS.BLOCKS` lists, their persisted layout, each block's sort (`SortOf`, `CycleSort`, `SortEntries`, the header's sort mark; round 3), the weapon block's filter (`FilterOf`, `SetFilter`, `FilterMenu`, `PaintFilter`, `FilterNote`, the header's `ph:funnel` filter mark and its menu; round 5, R5-10), detach / dock / collapse (and `SetAllCollapsed`, the window's Expand / Collapse all control; `SetCollapsedFor` and `DockAll`, a merged window's) through `NS.SetByPath` (`LAYOUT_CHANGED`), the entries each shows, the block header, the shared row layout pass; repaints every surface on the data and layout messages | declares the block titles through `NS.L` at load; subscribes on its own bus target |
| `modules/Detached.lua` | `NS.Detached`: a detached block's own HUD frame, its drag-only drop point (`StorePoint`: a split's landing), and the shared Detached windows style (`ApplyStyle`, round 5) | conventional |
| `modules/Groups.lua` | `NS.Groups`: merged detached windows (round 5, R5-6): the pure model `NS.Groups.Model` (merge on a side, split, normalize), the one owner of `layout.groups`, and the merged window (one band titled by the sections' short names with Collapse all and Dock all, a sub-header per section with chevron, title, filter (the weapon section), sort and split marks, columns side by side, the right-click menu); the Detached windows style | conventional: reads NS.Blocks and NS.Detached at call time |
| `modules/GroupsSnap.lua` | `NS.GroupsSnap`: the merged windows' drags (round 5, R5-6b, after AuraMaster's container snapping): the pure snap core (`Nearest`: the nearest target side within `SNAP_RADIUS` 24 with overlap along the other axis; `Column`; `Classify`: the `DETACH_RADIUS` 128 leeway), the throttled drag driver (`BeginWindow`, `BeginSection`, `Drop`, `Cancel`), the `sem.good` side highlight and the section ghost | conventional: reads NS.Groups and NS.Detached at call time |
| `modules/SecureOverlay.lua` | `NS.SecureOverlay`: the crafting rows' secure buttons (made, laid and shown only out of combat) and the combat queue `AfterCombat` | registers its two combat events on its own bus target at load |
| `modules/Interact.lua` | `NS.Interact`: the click map (design §6.5; Skinning and Fishing open their window by line ID, `OpenTradeSkill`; a weapon or Other row opens the Skills tab on its line, `OpenSkills`), shift-click to chat, the row menu (a second Pin unpins; from the LDB tooltip, Hide hides there) | conventional |
| `modules/RowTooltip.lua` | `NS.RowTooltip`: the row tooltip's lines (numbers, bar, bonuses with timers, session, next rank, cap gap, gathering and fishing helpers, stat markers, click hints) on GameTooltip | conventional |
| `modules/TrainerPopup.lua` | `NS.TrainerPopup`: the trainers for the faction, one card each, the waypoint and print actions; a card's "Also teaches" line wraps (up to four lines, one each past `P.MAX_HEIGHT`) and the card and window grow by its measured height (`P.TextHeight`, a secret or zero measure is one line; `P.Relayout`), the card's tooltip carries the whole list (round 5, R5-14); each card shows its distance (`"%d yd"`, none when unknown) and the cards sort nearest first, re-measured every `P.TICK` (1 s) by an AceTimer that runs only while the popup is shown, stopped on `OnHide` and restarted on `OnShow` (`P.Distance`, `P.RefreshDistances`, `P.Ticking`; round 5, R5-15) | conventional |
| `modules/Waypoints.lua` | `NS.Waypoints`: TomTom, else the native user waypoint, else chat directions | conventional |
| `modules/MainWindow.lua` | the main window: title band (lock; journal, settings, one Expand / Collapse all control showing what a click does, `AnyExpanded()`, and close), a body whose window width carries the scroll bar's whole gutter, summary strip (class icon, name in class color, level line; `Identity()`), docked blocks in one or two columns of a scrolled body, the player's strata, bonus legend (the marker drawn as a line), test strip, toggle, `ShowAndScrollTo(key)` (the broker's crafting rows), the two key binding buttons (window, Journal); the journal mark calls `NS.Journal.Toggle` | publishes `NS.BINDINGS` for the General page |
| `modules/Probe.lua` | `/sm probe`: the Forever API report as JSON in a copy window; `Summary()`, its read-only half for the diagnostics | reads only core members at load |
| `modules/SkillData.lua` | the skills model: scan, classify, synthesize unlearned rows, `SKILLS_UPDATED` / `SKILL_UP`; builds `NS.SkillNameToKey` | after the catalog and the locale, read at load |
| `modules/Trainers.lua` | `NS.Trainers`: `For(key, faction?, race?)` and `NextRank(...)` over the trainer and rank tables; the pure distance math, `Distance(a, b)` (yards between two `{ instance, x, y }`, nil across instances) and `ByDistance(list, dist)` (a new list, nearest first, the unmeasured last in their order) (round 5, R5-15) | reads the defaults at call time |
| `modules/Helpers.lua` | `NS.SkillHelpers`: skinnable level, weapon cap, fishing need, gatherable nodes, the equipped weapon skills (`NS.Helpers` is the options library) | reads the defaults at call time |
| `modules/Bonuses.lua` | `NS.Bonuses`: a skill's modifier broken into racial, item, enchant, buff and Other sources; `BONUSES_UPDATED` | defines `NS.addon:OnBonusesUnitChanged` at load, so after `core/SkillMaster.lua`; reads SkillData at call time |
| `modules/Diagnostics.lua` | the diagnostics report's sections: identity, settings, state (window, test mode, Sim mode), skin, model, probe, bonuses, layout, sim, rejected | read at run time |
| `modules/StatData.lua` | `NS.StatData`: the stats model over `NS.STAT_DEFS`, `STATS_UPDATED`, the speed ticker | registers its events on its own bus target at load |
| `modules/SessionLog.lua` | `NS.SessionLog`: the per-character ring of skill-ups (`db.char.log`, `journal.keep`, 500 by default; `SL.Cap()`), the read-only views test mode shows (`SL.View`) and a simulation's session-only override (`SL:Override`), session gains, `Rate`, per-skill `ETA`; hears `SKILL_UP` | subscribes on its own bus target at load (after `core/Bus.lua`) |
| `modules/Alts.lua` | `NS.Alts`: each character's skills and stats in `db.global.characters["<realm>-<name>"]` on `SKILLS_UPDATED` (debounced) and `PLAYER_LOGOUT`; `List`, `Forget`, `StatsOf` | subscribes on its own bus target at load; reads SkillData and StatData at call time |
| `modules/Journal.lua` | the Journal window: the Log tab (date and time per row, a LibKa0s range dropdown over `journal.range`) and the Alts tab (characters across, a sub-tab per `NS.BLOCKS` block, an `NS.Bar` mini bar per cell), each table's header on a band of the block headers' fill with the skin's divider under it (round 5), a lock mark beside the close control toggling `locked` (`ApplyLock`, from the setting's reaction, round 5), a resize grip (saved size, its default as the minimum, the screen as the maximum), the main window's test-mode strip under the title while test mode is on, the tabs and body moved down under it (round 6, R6-2), `/sm journal` | after Blocks (its sub-tabs read `NS.BLOCKS` at load); reads SessionLog and Alts at call time; repaints on `SKILLS_UPDATED` / `LAYOUT_CHANGED` |
| `modules/Alerts.lua` | `NS.Alerts`: the rank-cap and weapon-gap toasts (LibKa0s-Toast-1.0; `WeaponWatched`: the weapon modes and mute list, round 3), the cap's chat line, the click-to-waypoint (`NS.Waypoints:Set`); test mode's three sticky toasts from the sample, `ShowTestToasts` / `HideTestToasts`, round 5; every kind in the cap toast's skin look, the gap and skill-up numbers in the kind's color with the delta in brackets (`KindTitle`), round 6 | subscribes to `SKILL_UP` / `SKILLS_UPDATED` on its own bus target at load; reads SkillData, Trainers and the settings at call time |
| `modules/Template.lua` | `NS.Template.Render(tpl, ctx)`: the broker feed text tokens (`{pinned}`, `{gains}`, `{last}`, `{lowestProf}`, `{equippedWeapon}`, `{skill:<key>}`, `{stat:<key>}`, `{level}`); an unknown token renders empty | pure; read by Broker at call time |
| `modules/Broker.lua` | `NS.Broker`: the one LibDataBroker data source, "Skill Master" (FB-12), the skill-up flash, the tooltip's five sections (Primary, Secondary, Weapon, Other, Stats; `B.SectionShown`, `B.HiddenInTooltip`) in the window's look (each section under its block title on the header band, every other row striped, white names; `B.Bands`) with `NS.Bar` mini bars and clickable rows, drawn on its own GameTooltip-template frame painted with `NS.Skin.Shell` / `Text` while `broker.tooltip.skin` is on, else on the shared GameTooltip, which it never paints (FB-13; `B.Tip`, `B.HideTooltip`) (a crafting row calls `NS.MainWindow.ShowAndScrollTo`, an unlearned one `NS.TrainerPopup.Show`); test mode's line under the title (`B.AddTestModeLine`, the helper every tooltip it fills calls; round 6, R6-2); never the launcher, never secure | builds its data objects and bus target at load (after Bus, Pool and the libraries) |
| `modules/Preview.lua` | `NS.Preview`: test mode's data swap. Builds the sample's models through `SkillData.Build`, `StatData.Build` and `Bonuses.Compute`, sets `NS.Blocks.source`, `NS.Bonuses.source` and `NS.Broker.source`, and answers `Log()`, `Alts()`, `Skill(key)` and `Character()` for the Journal, the row tooltip and the summary line | conventional: reads its fixture and the data modules at call time |
| `modules/Simulator.lua` | `NS.Sim` (LibKa0s-Sim-1.0's instance, or the stub), `NS.SimHost`: the simulated world and its providers, `deliver`, the fishing-trip scenario, the refusals, the session-only stores and the restoring stop; `NS.IsSimMode` / `NS.ToggleSim` for the launcher and the checkbox | after every module it delivers to; `Sim:New` and the providers at load |
| `settings/Schema.lua` | the schema and the single write seam (LibKa0s-Schema-1.0) | before Slash, OptionsSetup and the pages |
| `settings/Slash.lua` | `NS.COMMANDS` and the dispatcher (LibKa0s-Slash-1.0) | before the landing spec reads it |
| `settings/OptionsSetup.lua` | the panel descriptor, `NS.Helpers` (LibKa0s-Options-1.0), `NS.Live`, `NS.TemplateRows` (a template's presets dropdown and its Custom box) | before every page file |
| `settings/General.lua` | landing spec, Master controls, Skin and Keybindings tabs | first page registered |
| `settings/BoxList.lua` | `NS.OptionsList`: the boxed list row (ConsumableMaster's Priority list look) the Rows page and Block order draw, with any number of action columns (`actionWidth`, `labelWidth`) and an unboxed `Header` line over them; its own AceGUI widgets (`SkillMasterListLabel`, `SkillMasterListHeading`, `SkillMasterListCaption`) | after OptionsSetup; read at render time |
| `settings/Layout.lua` | the Layout page: window, per-block rows, the Block order drag list on `NS.OptionsList` (handle, name, an eye for Show this block; `NS.OptionsBlockOrder`) | after General |
| `settings/Bars.lua` | the Bars page | after Layout |
| `settings/Skills.lua` | the Skills page (unlearned skills, the gathering hints); `NS.SortedSkillKeys`, the catalog in the window's order | after Bars |
| `settings/Rows.lua` | the Rows page (round 5, R5-13, `NS.OptionsRows`): the window's and the LDB tooltip's Hide rows for every catalog skill and stat, the four whole-set rows, drawn as boxed rows with two eyes under the window's block headings (`Groups`, `Render`); every hide write and every block reorder (a `LAYOUT_CHANGED` listener, `Rows.events`) redraws it, a bracketed batch once on the next frame | after Skills |
| `settings/Broker.lua` | the Broker page: feed templates, flash, the tooltip's section switches | after Rows |
| `settings/Alerts.lua` | the Alerts page | after Broker |
| `settings/Journal.lua` | the Journal page: log length, the Log's range, the Alts sub-tab on open | after Alerts |
| `settings/Trainers.lua` | the Trainers and Waypoints page | before Profiles |
| `settings/Profiles.lua` | the AceDBOptions Profiles page | last page registered |

`Bindings.xml` sits at the root beside the TOC and is never a TOC line (launcher-§6). It carries two
`CLICK` bindings, Show window first and then the Journal; `modules/MainWindow.lua` creates both buttons
(`SkillMasterToggleWindow`, `SkillMasterToggleJournal`), their labels and `NS.BINDINGS`.
`libs/` and `tests/_kit/` are vendored from LibKa0s v1.94.0 and never edited.
